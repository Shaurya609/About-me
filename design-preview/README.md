# Portfolio design preview

Open `index.html` through a local HTTP server to preview the selected direction:
Hudson-inspired typography and split introduction, combined with the user's
cream, bordered skills-grid reference. Design reference:
https://styleshout.com/free-templates/hudson/

This is a standalone design preview, not the deployed homepage. Detail links
lead to the existing education, work, designs and hobby pages. The existing
music page retains artist hover playback. All photos and project artwork come
from the repository's optimized assets. No stock testimonials or achievements
have been added. Skill descriptions and experience summaries use existing site
content; employment details still need a content refresh before final launch.

The 12 skills use lightweight monochrome text symbols, cream tiles, thin borders
and gold hover/selection states. Selecting a tile updates the description below
the grid. Four columns on desktop become two on mobile. Buttons support keyboard
activation, selection states and live description announcements. Reduced-motion
preferences disable animation. Navigation remains available without JavaScript.

Checked desktop and mobile rendering, skill selection, mobile navigation,
horizontal overflow, local links and image references. Production pages have
not been replaced and this preview has not been published.
